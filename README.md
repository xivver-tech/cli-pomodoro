# CLI Pomodoro

A proper Pomodoro timer for the terminal with history and stats.

## Features
- Classic 25/5 cycles (fully configurable)
- Live countdown
- Session history saved to disk
- Daily + total stats
- Clean, interruption-friendly

## Usage
```bash
# Default: 25 min work / 5 min break × 4 cycles
python pomodoro.py

# Custom: 50 min work, 10 min break, 2 cycles
python pomodoro.py 50 10 2

# See your stats
python pomodoro.py stats
```
